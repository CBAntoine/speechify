# Answer key

The Verifier grades the generator against this table. Each row is a question a teammate really asks you and the answer you'd give, in your own words. You are the source of truth.

**It's a living document.** Every time the generator gets something wrong, add that question as a new row with the answer you wanted (`/improve 1` does this for you from the conversation).

| Column | What goes in it |
| --- | --- |
| ID | A short name: letters, numbers and dashes. |
| Question | What the teammate asked, the way they'd ask it. |
| Ideal answer | Your answer, the way you'd write it. The Verifier uses it as the reference. |
| Must include | The points that decide right or wrong, separated by `;`. A rule about the answer works too ("says it doesn't know", "under 80 words"). Wording and tone aren't graded unless you put them here. |
| Held out | `yes` hides the row from the Coach. It's still graded on every run, so a draft that only teaches to the visible rows shows up here. Hold out about one row in four. |
| Added | When or why you added the row. It isn't graded. |

Inside a cell, write `\|` for a pipe and `<br>` for a line break.

**This repository is public**, so keep private answers out of this file. Put them in `evals/answer_key.private.md` instead, with the same columns. Git ignores that file, and the loop reads both.

The rows below are a starting set that Claude drafted from the READMEs. Replace them with the questions your teammates actually ask (`/interview` collects them), and rewrite any answer that isn't how you'd put it.
